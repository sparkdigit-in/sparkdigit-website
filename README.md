# Sparkdigit Website

Premium Next.js website starter for Sparkdigit.

## Stack
- Next.js 16
- React 19
- TypeScript
- Custom CSS
- Sparkdigit SVG logo

## Run locally

Install Node.js 20.9+ (Node 24 is recommended for current Next.js tooling), then:

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy

Push this repository to GitHub and import it into Vercel. Vercel automatically detects Next.js projects.

## Before launch
- Replace portfolio placeholder tiles with real client work.
- Add verified client results/testimonials.
- Replace placeholder contact email if needed.
- Add final WhatsApp number.
- Connect sparkdigits.in after final QA.
